# 🎮 Neon Tic-Tac-Toe (Крестики-Нолики)

Современная игра «Крестики-Нолики» с двумя режимами запуска:
1. **Консольный режим (CLI):** управление через Numpad (клавиши 1–9) на чистом Python.
2. **Мобильный графический интерфейс (Mobile Web UI):** стильный неоновый дизайн от **Google Stitch** с поддержкой темной темы, анимаций, звуковых эффектов (Web Audio API) и счетчиком побед/ничьих.

---

## 🚀 Как запустить игру

### Вариант 1: Мобильный UI в браузере (Рекомендуется)
Запустите лаунчер, который автоматически откроет красивую мобильную версию игры в браузере:
```bash
python3 app.py
```
*Или просто откройте файл `index.html` двойным кликом в любом браузере.*

### Вариант 2: Консольная версия в терминале
```bash
python3 main.py
```
*Управление ходами осуществляется цифрами от 1 до 9 в раскладке Numpad (1 — левый нижний угол, 9 — правый верхний угол).*

---

## 🛠 Технологии и особенности
- **Python 3:** базовая логика игры, валидация ходов, проверка побед и ничьих, локальный HTTP-сервер.
- **Google Stitch:** генерация UI-макета мобильного экрана через Model Context Protocol (MCP).
- **Tailwind CSS & Material Symbols:** адаптивная неоновая верстка под мобильные устройства.
- **Web Audio API:** синтезированные звуковые эффекты ходов и победы без сторонних аудиофайлов.
- **Git & GitHub:** контроль версий проекта.
